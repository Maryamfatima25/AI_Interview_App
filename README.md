# AI-Based Interview & Recruitment System 

A Flutter-based mobile application that simulates a modern recruitment platform where applicants can apply for jobs and experience an AI-driven interview process, while recruiters can efficiently manage and evaluate candidates.

This project was developed as a semester project to demonstrate role-based authentication, recruitment workflows, interview simulations, and dynamic data handling using Flutter.

---

## 📌 Project Overview

The system provides two main user roles:

### 👨‍💻 Applicant
- Browse available jobs
- Apply for jobs
- Take AI-based mock interviews
- Receive interview evaluations
- Track application progress

### 👩‍💼 Recruiter
- Post new jobs
- View all applicants
- Filter candidates by job role
- Analyze interview scores and skills
- Compare candidates

---

## ✨ Features

### 🔐 Authentication System
- Login & Signup functionality
- Role-based access (Applicant / Recruiter)
- Navigation control using `pushAndRemoveUntil()`

### 📄 Job Application System
- Job browsing
- Application submission forms
- Skill matching & validation

### 🤖 AI Interview Simulation
- Mock AI interview process
- Dynamic scoring system
- Automated evaluation results

### 📊 Recruiter Dashboard
- Candidate filtering
- Skill tags & score display
- Candidate comparison system

### ⚡ Data Handling
- Local JSON-based demo data
- In-memory runtime storage
- Dynamic recruiter view updates
